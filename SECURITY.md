# Security Policy

## Reporting a Vulnerability

If you discover a potential security issue in this project, we ask that you
notify AWS/Amazon Security via our
[vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/)
or directly via email to [aws-security@amazon.com](mailto:aws-security@amazon.com).

Please do **not** create a public GitHub issue for security vulnerabilities.

## Scope

This repository contains **sample code** provided for demonstration and
educational purposes. It is not intended for production use as-is. Before
deploying any part of this sample into your own environment, review the
[threat model](docs/THREAT_MODEL.md) and address the documented residual risks
(for example, scoping IAM permissions and restricting who can upload documents
and corrections).
